# Hollow Deer

A 2D dungeon platformer where a deer fights its way through a wolf's dungeon to get back its stolen antlers.

## Godot version
4.7

## How to run
1. Clone the repo.
2. Open `hollow-deer/project.godot` in Godot 4.7.
3. Press F5.
